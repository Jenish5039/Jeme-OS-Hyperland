# Machine-Specific Configuration Layer

Jeme OS strictly separates **portable desktop configurations** from **machine-specific hardware settings**.

---

## 1. Why Separate Machine Configuration?

When installing Jeme OS across different physical machines:
* **Monitors differ**: One PC might have `eDP-1` at 1080p 144Hz, another might have `DP-1` at 4K 165Hz or dual monitors (`DP-1` + `HDMI-A-1`).
* **GPUs differ**: NVIDIA requires proprietary Wayland driver flags (`LIBVA_DRIVER_NAME=nvidia`, `__GLX_VENDOR_LIBRARY_NAME=nvidia`, `NVD_BACKEND=direct`), whereas AMD Radeon uses open-source Mesa drivers (`radeonsi`), and Intel uses `iHD`.
* **Hardware identifiers differ**: Battery, backlight control interfaces (`/sys/class/backlight/...`), and audio sink names can vary.

---

## 2. Managed Machine Files

The following files are generated or selected per machine upon installation and are not overwritten blindly by general updates:

| File Path | Description | Typical Source |
|---|---|---|
| `~/.config/hypr/monitors.lua` | Native Lua monitor configuration | Auto-generated by `machine/detect.sh` or `nwg-displays` |
| `~/.config/hypr/monitors.conf` | Plain-text monitor fallback | Auto-generated |
| `~/.config/hypr/conf/environment.lua` | GPU-specific environment variables | Linked/copied based on GPU vendor (NVIDIA / AMD / Intel) |

---

## 3. Hardware Auto-Detection Tool

Run the interactive/automated hardware prober:
```bash
./machine/detect.sh
```
or via the Jeme CLI:
```bash
jeme detect
```

This script:
1. Detects all connected monitors via `hyprctl monitors` or `/sys/class/drm/*/status`.
2. Probes active GPU(s) (`lspci`, `glxinfo`, `nvidia-smi`).
3. Writes clean, valid Lua configuration to `~/.config/hypr/monitors.lua`.
4. Activates the appropriate GPU environment variant (`nvidia.lua`, `amd.lua`, `intel.lua`, or `default.lua`).

---

## 4. Hardware Profiles / Examples

Preset hardware profiles are provided in `machine/examples/`:
* `machine/examples/nvidia-laptop/`: Dedicated/Hybrid NVIDIA laptop with high-refresh display and PRIME offloading.
* `machine/examples/amd-desktop/`: Pure AMD CPU + Radeon GPU desktop with DisplayPort VRR setup.
* `machine/examples/intel-laptop/`: Intel Core iGPU laptop with battery-optimized settings.
